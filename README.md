
# 🍅 TOMATO – Food Ordering App UI/UX Design

TOMATO is a modern food ordering mobile app UI/UX design created using **Figma**.  
The app focuses on clean visuals, smooth user experience, and real-world app functionality.

## 🚀 Features
- Home screen with category filters
- Smart search experience
- Advanced filter bottom sheet
- Buy item page with customization options
- Instagram-style user profile dashboard

## 🎨 Design Highlights
- Clean and minimal UI
- Consistent red & white theme
- Proper spacing & typography
- Auto Layout & reusable components

## 🛠 Tools Used
- Figma
- UI/UX principles
- Auto Layout & Prototyping

## 🎯 Project Goal
To design a **production-ready food ordering app UI** that feels realistic and user-friendly.
